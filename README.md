## Selected Projects

### IoT-Based Intelligent Rodent Monitoring System

**ESP32 · MQTT · Flask · Firebase · HC-SR04 · MQ-135**

An IoT-based monitoring and automated diffusion system designed for environments where rodent activity can pose a risk to critical infrastructure.

The system combines sensor-based detection, MQTT communication, backend processing, database integration, and automated response mechanisms.

**[View Repository →](https://github.com/Misbah81/IOT_based_Rodent-detection-system)**

---

### Footstep Power Generation

**Arduino Uno · Piezoelectric Sensors · Voltage Sensing · I2C LCD**

A hardware prototype that explores electrical energy generation from human footsteps using piezoelectric sensors, with voltage monitoring and LCD output.

**[View Repository →](https://github.com/Misbah81/Footstep-Power-Generation)**

---

### Raspberry Pi LED Control
